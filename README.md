# Coffee Shop Aroma Website

A modern and responsive coffee shop landing page created using HTML and CSS.

## Features

- Responsive design
- Modern and cozy coffee shop interface
- Sticky navigation bar
- Hero section with featured product
- About section
- Featured menu
- Customer reviews section
- Contact and reservation section
- Responsive layout for desktop, tablet and mobile devices

## Technologies Used

- HTML5
- CSS3

## Sections

- Our Story
- Featured Menu
- Reviews
- Contact Us
- Quick Reservation
